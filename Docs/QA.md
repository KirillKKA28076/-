# Проверка версии 0.1

## Честный статус

В среде автора этого коммита Unity Editor / C# compiler отсутствуют. Unity build, EditMode-тесты и PlayMode пока **не запускались**. `Tools/validate_project.py` проверяет C# grammar через tree-sitter, JSON, метаданные, ссылку сцены и глифы шрифта — не Unity API и не поведение игры.

## Локальная проверка в Unity

1. Открыть корень проекта в Unity 2022.3.62f1, дождаться импорта пакетов.
2. Запустить `Тёплый хлеб → 1. Подготовить проект`; проверить отсутствие красных ошибок Console.
3. Открыть `Assets/WarmBread/Scenes/Bakery_Street.unity`. Нажать Play. Мир должен появиться, не быть розовым; русский текст должен читаться.
4. Нажать «Открыть ларёк». Проверить WASD, мышь, E, лучи сквозь окно, полки; игрок не проходит через стену и прилавок.
5. Дождаться покупателя. Проверить заказ из 1–3 единиц, отображение и продвижение очереди.
6. Собрать лишний товар: выдача должна отказать. X должен вернуть всё с неизменным bakedAt.
7. Собрать правильный заказ. Неверная сдача не меняет кассу. Верная добавляет ровно сумму покупки один раз и закрывает экран.
8. Пропустить покупателя: через 120 секунд он уходит, пакет возвращается, репутация уменьшается. Следующий клиент продвигается.
9. Дождаться конфликта: F/E у окна успокаивает, не должно быть мгновенного повторного конфликта.
10. Заказать ящик: деньги списываются один раз; через 25 секунд появляется 10 товаров. При недостатке денег или четырёх доставках новые заказы запрещены.
11. Проверить просрочку пирожков после 6 игровых часов; бутылки не портятся.
12. Esc останавливает время, очередь, машины и звук. После возврата работают UI и mouse look.
13. Досрочно закрыть смену. Аренда 50 ₽ списывается ровно один раз. Перейти к следующему дню, перезапустить, нажать «Продолжить».
14. Проверить backup: скопировать сохранения в безопасную папку, повредить только тестовый основной JSON и убедиться в чтении `.bak`.
15. Отдельно проверить клики кассы/блокнота в кадр начала смены/ухода NPC. Нет старых активных кнопок после Refresh.

## Автоматические тесты

`Window → General → Test Runner → EditMode → Run All`.

Из командной строки (замените UNITY_EDITOR на путь установленного лицензированного редактора):

```bash
"$UNITY_EDITOR" -batchmode -projectPath . -executeMethod WarmBread.Editor.ProjectSetup.Prepare -quit -logFile prepare.log
"$UNITY_EDITOR" -batchmode -projectPath . -runTests -testPlatform EditMode -testResults test-results.xml -logFile tests.log
"$UNITY_EDITOR" -batchmode -projectPath . -executeMethod WarmBread.Editor.ProjectSetup.BuildWindows -quit -logFile build.log
```

Тесты не запускаются автоматически в GitHub Actions: лицензия Unity не настроена. Не добавляйте её в файлы проекта.

## Визуальная приёмка

- 16:9 720p/1080p; затем 16:10 и 21:9. Проверить края UI; полноэкранные панели сейчас рассчитаны прежде всего на 16:9.
- Посмотреть сцену при 06:00, 12:00 и 19:30. Проверить читаемость NPC против окна и света в ларьке.
- Нет дождя внутри, заметного z-fighting, розовых материалов, чрезмерного bloom.
- FPS/CPU/GPU/GC измерять в Development Build, а не обещать по сложности исходников.
- Сделать реальные скриншоты из Unity и записать короткое прохождение. В репозитории нет выдаваемых за игру AI-рендеров.
