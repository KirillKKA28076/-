# Архитектура 0.1

## Входная точка

`Bakery_Street.unity` → `GameBootstrap.Start`: шрифт → сессия/каталог → очередь → UI/атмосфера → мир/NavMesh → FPS → аудио/интерфейс.

Сцена хранит стабильную ссылку на `GameBootstrap.cs`. Метаданные Unity закоммичены. Скрипт редактора идемпотентно создаёт настройки URP и ресурсы; существующие ProductData не перезаписывает. Параллельные изменения `main` не заменяются: версия сцены развивается в `warm-bread-playable-v01`.

## Модули

| Модуль | Ответственность |
|---|---|
| ProductData / CustomerData | Редактируемые определения ассортимента и людей |
| Inventory / StockBatch | FIFO, партии, время приготовления, резервирование в пакет |
| Order / Money | Состав заказа, цена на момент создания, целые копейки |
| GameSession | Смена, касса, доставка, репутация, завершение транзакции |
| QueueManager / CustomerAI | Список ожидания, NavMesh, состояния, уход и конфликт |
| PlayerController / InteractionTarget | New Input System, raycast, действия на объектах |
| WorldBuilder / WorldArt | Детерминированное окружение и общие материалы |
| Atmosphere | Дневной свет, дождь, оригинальная синтезированная музыка/SFX |
| GameUI | Canvas/TMP: меню, HUD, блокнот, касса, итоги и пауза |
| SaveSystem / SaveData | Версионированный checkpoint, временный файл и backup |
| ProjectSetup | Импорт TMP Essentials, URP, каталог, Build Settings и сборка |

## Транзакция продажи

1. Заказ генерируется только из имеющегося ассортимента (для ребёнка без сигарет); его общая цена фиксируется.
2. `Inventory.Take` резервирует единицу из самой старой партии; оригинальное `bakedAt` остаётся у пакета.
3. Выдача разрешена только при полном совпадении состава и количества; лишний товар не игнорируется.
4. Стадия Paying блокирует изменение пакета. До правильной сдачи касса не пополняется.
5. Неверная сдача уменьшает доверие и оставляет ту же транзакцию открытой. Верная — единожды добавляет сумму покупки, очищает пакет и выводит NPC из очереди.
6. При уходе/закрытии пакет возвращается с исходным сроком годности. До оплаты ошибочная сдача не является переданной суммой.

## Сохранение и ограничения

Хранится начало дня. На границе дня очередь удаляется, пакет возвращается, оплаченные поставки завершаются. На следующий день проверяется срок годности; затем новый checkpoint записывается через `.tmp` и `File.Replace` с `.bak`. Загрузка отбрасывает неподдержанную версию и некорректные базовые значения, пробует backup.

Версия 1 не выполняет миграций других схем, не защищает от ручного читерства, не восстанавливает очередь и не сохраняет каждую продажу. Статический EventBus сбрасывается при SubsystemRegistration, чтобы отключение Domain Reload не накапливало подписки.

## Технические источники

- [AI Navigation / NavMeshSurface](https://docs.unity3d.com/Packages/com.unity.ai.navigation@1.1/manual/NavMeshSurface.html): сбор уличных дочерних коллайдеров и BuildNavMesh.
- [URP 14 / UniversalRenderPipelineAsset](https://docs.unity3d.com/Packages/com.unity.render-pipelines.universal@14.0/api/UnityEngine.Rendering.Universal.UniversalRenderPipelineAsset.html): создание pipeline из renderer data в редакторе.
