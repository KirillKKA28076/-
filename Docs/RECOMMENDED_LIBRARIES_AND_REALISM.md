# Рекомендованные библиотеки и инструменты — «Тёплый хлеб»

Дата: 2026-09-20  
Цель: реалистичный атмосферный 3D-проект на Unity 2022.3 LTS.

## Уже установлено

- Universal Render Pipeline 14.0.11 — освещение и материалы.
- Input System 1.7.0 — современное управление.
- AI Navigation 1.1.5 — NavMesh и навигация NPC.
- TextMeshPro 3.0.6 — русский UI и субтитры.
- Test Framework 1.1.33 — автоматические тесты.
- Audio, Physics, Particles, JSON и UI modules.

## Добавить через Package Manager

| Пакет | Рекомендуемая версия | Зачем |
|---|---:|---|
| Cinemachine | 2.9.7 | FPS-камера, мягкая тряска, переходы |
| Addressables | 1.21.21 | загрузка ассетов без огромной сцены |
| Localization | 1.4.5 | русский/английский, таблицы строк |
| ProBuilder | 5.2.2 | блок-аут ларька и улицы внутри Unity |
| Recorder | 4.0.2 | трейлеры и запись тестовых сцен |

После открытия проекта Unity сама создаст Packages/packages-lock.json. Не генерировать lock-файл вручную.

## Что не нужно добавлять сейчас

- DOTS/ECS — преждевременно для небольшого симулятора.
- Photon, Mirror, Netcode — мультиплеер не заявлен.
- Firebase и внешние SDK — нет онлайн-сервиса.
- Behaviour Tree — архитектура использует State Machine.
- Платные ассеты без подтверждённой лицензии.
- Случайные DLL из интернета.
- PlayerPrefs для прогресса, денег и настроек с чувствительными данными.

## Рекомендованный стек реализма

### Свет

- URP Volume: Color Adjustments, Bloom умеренной силы, Vignette, Film Grain.
- Baked Global Illumination для интерьера.
- Один основной Directional Light с мягкими тенями.
- локальные Point/Area-подобные источники в ларьке.
- Reflection Probe внутри витрины и у окна.
- Light Probe Group для NPC и движущихся объектов.
- Не включать тяжёлые эффекты по умолчанию на слабых видеокартах.

### Материалы

- физически корректные значения в URP Lit;
- отдельные маски грязи, потёртости, влаги и пыли;
- decals только для крупных деталей;
- trim-sheet для ларька и мебели;
- atlas для мелких предметов;
- материалы без лишнего transparency;
- стекло витрины — отдельный простой шейдер с ограниченной сортировкой.

### Окружение

- modular kit ларька;
- atlas для асфальта, бетона, краски, металла и старого пластика;
- LOD для домов, машин и деревьев;
- occlusion culling между улицей и ларьком;
- GPU instancing для повторяющихся окон, деревьев и проводов;
- baked NavMesh для улицы и отдельный NavMeshSurface для интерьера.

### Анимации и NPC

- Animator Controller с понятными состояниями;
- NavMeshAgent не должен напрямую владеть бизнес-логикой заказа;
- object pooling для NPC и эффектов;
- IK использовать только там, где он заметен в кадре;
- дальние NPC переходят в упрощённый режим;
- случайность через seedable RNG для воспроизводимых багов.

### Звук

- AudioMixer группы Master/Music/Ambience/SFX/Radio/Voice;
- low-pass фильтр для звуков снаружи;
- reverb zone внутри ларька;
- лимит одновременных голосов;
- вариации шагов, монет, дверей и чайника;
- музыка и радио только с проверенной лицензией;
- хранить источник и лицензию каждого аудиофайла в AudioCatalog.

## Архитектурные библиотеки проекта

Это собственные модули, а не внешние скачиваемые пакеты:

- EventBus — типизированные события;
- GameFacade — команды для UI и адаптеров;
- WorldClock — время и расписания;
- SaveSystem — атомарные JSON-сохранения, backup, миграции;
- SettingsService — настройки и accessibility;
- LocalizationService — ключи и fallback;
- EconomyLedger — безопасные операции с деньгами;
- DeliveryService — заказы поставщику;
- JournalService — истории покупателей;
- RelationshipService — отношения с районом;
- AchievementService — достижения;
- ObjectPool — NPC, частицы, декали;
- GameLog — ограниченный диагностический журнал;
- ContentValidator — проверка ScriptableObjects, ID и ссылок.

## Технические лимиты

- целевой FPS: 60;
- целевое время кадра: до 16.6 ms;
- GC Alloc в обычном кадре: 0 B в горячих системах;
- NPC одновременно: 12–20, масштабировать профилированием;
- draw calls: проверять на реальном тестовом билде;
- сохранение: только по событиям, не каждый кадр;
- никакой сети без отдельного решения о сетевой архитектуре.

## Порядок установки

1. Открыть проект в Unity 2022.3.62f1.
2. Дождаться разрешения текущих пакетов.
3. Добавить Cinemachine, Addressables, Localization, ProBuilder и Recorder через Package Manager.
4. Проверить совместимость и дождаться генерации packages-lock.json.
5. Создать базовые настройки URP и Volume Profile.
6. Настроить Input Actions и Cinemachine.
7. Создать Addressables Groups только после появления повторно используемых ассетов.
8. Запустить EditMode и PlayMode tests.
9. Сделать Windows Development Build и проверить на чистой машине.
