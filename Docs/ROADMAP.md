# Дальнейшее развитие после версии 0.3

Версия 0.3 уже содержит законченный игровой цикл: семидневную кампанию, ежедневные цели, экономику, поставки, очередь, сохранения, три финала, свободный режим и детализированный процедурный 3D-мир.

Ниже перечислены не обязательные части основного сюжета, а этапы превращения законченного прототипа в коммерчески отполированный релиз.

## 1. Блокирующее перед публичным билдом

- Чистая компиляция в Unity 2022.3.62f1.
- Все EditMode-тесты зелёные.
- Семидневный PlayMode-проход.
- Проверка всех трёх финалов.
- Windows Development Build на чистой машине.
- Профилирование CPU, GPU, памяти и GC.
- Проверка UI в 720p, 1080p, 16:10 и ultrawide.
- Исправление всех найденных коллизий, NavMesh-разрывов и визуальных артефактов.

## 2. Production-модели

Текущие модели создаются собственным процедурным генератором и подходят для цельного стилизованного прототипа. Следующий художественный уровень:

- ручные low-poly/high-poly источники;
- единый texel density;
- UV-атлас окружения;
- trim sheet ларька и домов;
- vertex color для грязи и мокрых краёв;
- отдельные LOD;
- impostor для дальних деревьев;
- авторские риги персонажей;
- blend shapes лиц;
- IK рук у кассы и пакета;
- анимации походки, ожидания, разговора и передачи денег.

## 3. Освещение и оптимизация

- Baked GI для ларька и фасада.
- Light Probe Group для NPC.
- запечённые Reflection Probes для стабильного билда;
- Occlusion Culling;
- Static Batching;
- атласы материалов;
- объединение мелких мешей домов;
- LODGroup автомобилей и деревьев;
- асинхронная или заранее запечённая навигация;
- измеренный бюджет draw calls и SetPass.

## 4. Звук

- AudioMixer: Master / Music / Ambience / SFX / Radio / Voice;
- записанные оригинальные шаги по разным поверхностям;
- бумажный пакет, монеты, касса, телефон и чайник;
- пространственный дождь снаружи;
- low-pass для улицы через закрытую стену;
- reverb внутри ларька;
- голосовые реплики только с подтверждёнными правами;
- субтитры и настройка громкости категорий.

## 5. Расширение механик

Не требуется для завершения текущей истории, но может стать версией 0.4+:

- печь и выпечка;
- ручная выкладка на подносы;
- физический денежный ящик с конечным запасом номиналов;
- изменение розничных цен;
- отношения с каждым покупателем;
- ветвящиеся диалоги;
- районные события;
- сезон после сентября;
- ремонт и улучшения ларька;
- сохранение посреди смены;
- дополнительные кампании.

## 6. Доступность и локализация

- переназначение клавиш;
- отдельные настройки head-bob, FOV, чувствительности и motion reduction;
- масштаб UI;
- режим высокой контрастности;
- субтитры всех звуковых реплик;
- русский и английский через Unity Localization;
- проверка шрифта для всех локалей.

## 7. Релизная подготовка

- лицензия исходного кода;
- аудит шрифта, звука и всех импортированных материалов;
- реальные скриншоты из билда;
- трейлер из Unity Recorder;
- crash log и версия сборки;
- страница игры;
- архив символов Development Build;
- changelog и список известных ограничений.

## Правило развития

Новый пакет или ассет добавляется только после проверки:

1. отдельная ветка;
2. один пакет за раз;
3. компиляция;
4. EditMode/PlayMode;
5. измерение размера билда;
6. измерение времени кадра;
7. фиксация версии и лицензии.

Не смешивать несколько систем погоды, сохранений, DI, tween или диалоговых фреймворков без доказанной необходимости.
