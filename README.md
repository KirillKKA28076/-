# Тёплый хлеб

**Маленький ларёк. Большой двор. Сентябрь, 2002.**

Атмосферный 3D-симулятор от первого лица по вашему концепт-документу: ручная сдача, свежая выпечка, очередь и маленькие истории соседей. Холодный дождливый двор с панельками снаружи, выцветшая бирюза и тёплый свет лампы внутри.

## Что это за версия

Версия **0.1 — исходники первого вертикального среза**, не готовый коммерческий релиз. Модели, материалы и звук создаются процедурно. Это самостоятельная стилизованная основа, а не фотореалистичный комплект купленных ассетов.

**Важно:** Unity Editor отсутствует в среде разработки. Компиляция Unity, PlayMode, визуальная проверка и Windows-сборка здесь не выполнялись. Статическая проверка исходников не доказывает, что билд уже работает. До распространения обязательно выполните [чек-лист проверки](Docs/QA.md).

## Открыть и запустить

1. Скачайте **ветку `warm-bread-playable-v01`**, либо клонируйте её:

   ```bash
   git clone --branch warm-bread-playable-v01 https://github.com/KirillKKA28076/-.git WarmBread
   ```

2. В Unity Hub: **Add → Add project from disk**, укажите папку с `Assets`, `Packages`, `ProjectSettings`.
3. Откройте в **Unity 2022.3.62f1**. Для Windows-билда установите Windows Build Support. При первом импорте нужен интернет для официальных Unity-пакетов.
4. Дождитесь окончания импорта. Скрипт `ProjectSetup` автоматически подготовит URP, TMP Essential Resources и редактируемые ScriptableObject-товары. При необходимости: **Тёплый хлеб → 1. Подготовить проект**.
5. Выберите **Тёплый хлеб → 2. Открыть игровую сцену**, затем **Play**. В меню игры нажмите **Открыть ларёк**.

В сцене до Play виден только `Warm Bread Bootstrap`: окружение детерминированно строится при запуске. Это предусмотрено архитектурой, а не потерянные ассеты.

## Первый покупатель

Через несколько секунд покупатель выйдет из-за угла и подойдёт к окну. Его заказ появится слева. Развернитесь к полкам и берите нужные товары клавишей E; также можно выбрать их в блокноте (Tab → Прилавок). Нажмите F, наберите сдачу кнопками монет/купюр и передайте пакет. Лишний товар возвращается клавишей X до передачи заказа.

| Управление | Действие |
|---|---|
| WASD / мышь | Ходьба / обзор |
| E / ЛКМ | Взаимодействие с объектом под прицелом |
| F | Выдать заказ / открыть кассу / успокоить конфликт |
| X | Вернуть собранный пакет на полки |
| 1 / 2 / 3 / 4 | Батон / мясной пирожок / лимонад / жвачка |
| ПКМ | Приблизить взгляд |
| Tab | Блокнот: ассортимент, поставки, истории |
| R | Две оригинальные радиопетли / выключить радио |
| Esc | Пауза, настройки, досрочное закрытие смены |

## Реализовано в исходниках

- Процедурный район: пять панельных домов, балконы, тополя, скамейки, остановка, провода, седаны, проезжающая машина, мокрый асфальт и лужи.
- Ларёк с вывеской, козырьком, полками и десятью товарами, кассой, телефоном, чайником, календарём и котом Плюшем.
- URP: мягкие тени основного света, тёплые локальные источники, туман, bloom, ACES, vignette, film grain, дождь и плавное изменение дневного света.
- FPS с коллизиями, простыми процедурными руками и пакетом. Покачивание камеры отключается, чувствительность и звук регулируются в паузе.
- Шесть типов покупателей, NavMesh, пять состояний поведения, очередь до шести человек, ожидание и уход, конфликт с возможностью вмешаться.
- Точный заказ, ручная сдача, ошибки без дублирования оплаты. Деньги хранятся целыми копейками.
- Начальный запас по 10 каждого товара, касса 500 ₽; аренда 50 ₽. День с 06:00 до 20:00 занимает 15 минут.
- Поставки по 10 единиц за закупочную цену; доставка 25 секунд; до четырёх ящиков в пути.
- Партии товара и FIFO, срок годности, возврат без обновления срока, списание просрочки.
- Итоги дня, репутация, дневник с историями. Школьник не заказывает сигареты.
- JSON checkpoint начала смены с резервной копией; после следующего дня записывается новый checkpoint.
- Кириллический шрифт включён, лицензия находится в `Docs/FONT-LICENSE.txt`.
- EditMode-тесты денег, партий, заказов, каталога и сериализации.

## Сохранения

Файл `warm-bread-v1.json` хранится в `Application.persistentDataPath` — на Windows обычно `%USERPROFILE%/AppData/LocalLow/WarmBread/Тёплый хлеб/`. Старый файл сохраняется как `.bak`. Новая история требует второго нажатия, если сохранение уже существует.

**Внутри смены прогресс не сохраняется.** При перезапуске смена начинается с её checkpoint; очередь, пакет и незаконченные операции не восстанавливаются. Нажмите «Завтра в шесть» после отчёта, чтобы сохранить переход к новому дню. Настройки камеры и громкости пока действуют только до перезапуска.

  ```bash

  python Tools/validate_project.py
  ```

## Границы первой версии

Нет ригованных персонажей/Mixamo, полноценного IK, физического перекладывания каждого предмета, печи и мини-игры выпечки, смены сезонов, озвученных диалогов, сохранения посреди смены, физического ящика с ограниченными номиналами и отдельного калькулятора. У моделей намеренно простой геометрический стиль. Пакет — визуальный индикатор, а не физический контейнер. NavMesh строится при старте, GI не запечён. Поставщик пополняет полки событием, не привозит анимированную газель. Лужи — гладкие поверхности, не planar-reflections.

Список развития: [ROADMAP](Docs/ROADMAP.md). Архитектура: [ARCHITECTURE](Docs/ARCHITECTURE.md). Существующий [чек-лист библиотек и реализма](Docs/RECOMMENDED_LIBRARIES_AND_REALISM.md) сохранён; он описывает также будущие рекомендации, а не подтверждённо реализованные функции текущей версии. Дополнительные рекомендованные пакеты для запуска этого среза не требуются.

Никаких API-ключей, телеметрии, онлайн-сервисов или сторонних записей реальных радиостанций нет.
