# Тёплый хлеб

Атмосферный 3D-симулятор хлебного ларька в постсоветском дворе начала 2000-х.

Unity 2022.3 LTS • URP • C# • русский интерфейс.

## Статус

Проект создаётся поэтапными коммитами. Первый checkpoint: товары, заказы, деньги, склад, данные покупателей и сохранение. Сцена и игровой цикл будут добавлены следующими коммитами. Текущий checkpoint ещё не является запускаемой игрой.

В этой среде Unity Editor отсутствует: сборка и визуальная проверка в Unity пока не выполнены. Не выдаём исходники за проверенный Windows-билд.
